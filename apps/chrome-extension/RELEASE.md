## 构建与复核

使用 Node.js 22.12+ 与系统 `zip` / `unzip`：

```sh
cd apps/chrome-extension
npm ci
npm test
npm run build
npm run check:release
npm run release
```

`release` 会先运行测试，再清理构建、核对扩展身份和资源，生成 `release/isnips-2.0.0.zip`、SHA-256 文件与 `package-report.json`，并检查 ZIP 完整性。禁止携带 `ISNIPS_MANIFEST_KEY`、`ISNIPS_OAUTH_CLIENT_ID`、`ISNIPS_NAME_SUFFIX` 开发覆盖值发布。ZIP 根目录就是 manifest，不含源码工程、测试、依赖或开发配置。

自动回归包括：自动备份的定时触发、启动恢复、快照轮换、失败重试、并发合并及还原；记录合并；模拟 WebDAV/Drive 的失败响应与条件写入；真实 IndexedDB API 的内存实现中验证 v5 重开、旧备份、删除标记和事务；DOM 模拟验证阅读、撤销、草稿、失败保存、快捷键、语言和设置。**没有启动浏览器，没有连接真实同步账号。DOM 模拟不能证明真实排版或 Chrome 权限行为。**

## Brave 网页授权（2026-10-16）

- 设置统一显示“连接”，Chrome 默认继续使用原 `getAuthToken()`，Brave 自动选择网页通道。通过 Brave API、浏览器品牌信息及设置页传给后台的本机浏览器标记判断；没有明确标记且原生 API 明确不受支持时回退到网页通道，普通登录失败或取消授权不触发第二次授权。删除指导用户手动选择网页通道的提示。
- 仅连接成功时显示“断开连接”。关闭同步或切换服务清理本机 Google 令牌与连接状态，保留记录和自动备份设置；重新选择 Google Drive 后可以重新连接。连接与同步期间禁用冲突操作，其他设置页收到变更后刷新状态。
- Google Cloud 项目 `icctwh` 中已创建独立 Web 客户端 `iSnips Brave Web`，公开 Client ID 写入 `google-auth-config.js`，原 Chrome 客户端及扩展 ID 不变。密钥由项目所有者自行下载保存，未进入源码、备份或发布包。
- 2026-10-16 用户先确认 Brave 网页连接成功，随后点击“立即同步”并确认“同步成功，记录正常”。浏览器重启、令牌到期后的续接及跨设备变更同步仍待验收。
- 后续用户反馈重新选择服务时按钮状态残留，并报告网页连接偶发报错已自行恢复。本次统一连接入口与关闭/重开状态修复通过离线回归；偶发错误原因尚未确认，修复后的真实 Brave 流程尚未重新验收。
- 当前兼容实现使用 Google 前端短效 access_token 流程，不新增服务端，不持有 Client Secret 或 refresh_token。令牌只在受信任的扩展 session storage 中缓存；到期后台尝试 `prompt=none` 静默连接，Google 网页会话不可用时要求用户重新连接，不保证长期离线续期。Google 官方已建议新应用优先使用 GIS；该直接授权兼容路径的限制见 GOOGLE_WEB_AUTH.md，真实验收前不宣称正式支持。
- 严格验证 OAuth state、回调 origin/path、令牌类型、期限和返回的权限；回调中敏感 URL 不进入日志。401 仅尝试一次静默续接，自动任务不弹出交互窗口。
- 网页模式断开仅清理本机网页凭据与同步配置，不调用可能影响同项目其他设备的全局撤权；Chrome 原有断开行为保留。
- 网页同步看不到原同步库时先要求用户检查或确认新建，不会静默创建另一套库；原 Drive 路径、drive.file 范围、记录/文件夹格式及 WebDAV 保留。

## 文件夹云同步（2026-10-16）

- 现有手动与定时同步同时传输记录和文件夹名称、排序、归属、更新版本及删除标记，沿用已有 WebDAV / Google Drive 地址和授权。
- 文件夹改名按更新版本合并；相同版本采用稳定规则，删除对同一文件夹 ID 永久生效，旧文件、旧备份导入及离线改名不会自动复活已删除文件夹。重新创建同名文件夹会使用新 ID。
- 文件夹与记录在同一个 IndexedDB 事务中合并，非法文件夹数据先拒绝、写入失败整体回滚；删除文件夹不提高正文版本，离线文本编辑仍可合并，记录归回未分类。
- 云端文件夹字段使用白名单，不上传导入对象中的任意附加属性、偏好、账号凭据或剪贴板历史。数据库保持 v5，旧备份继续读取。
- 各设备需更新到本构建；旧客户端重写共享文件时可能省略文件夹字段。新客户端读取旧版仅记录文件时保留本机文件夹和删除标记。
- 离线双设备与模拟 WebDAV / Drive 测试覆盖创建、改名、删除、离线正文冲突、旧数据、原子回滚、已有文件更新及新 Drive 文件创建。用户已确认真实 Brave 手动同步成功、记录正常；真实云端文件夹操作与双设备冲突仍待逐项验收。

## 权限与数据披露填写依据

| 权限 | 当前用途 |
| --- | --- |
| storage | 偏好、会话草稿、恢复副本、本地快照和最多 99 条本机剪贴板历史 |
| unlimitedStorage | 保存用户持续积累的记录与本地备份 |
| activeTab | 用户打开扩展时访问当前网页，用于附上来源 |
| sidePanel | 侧栏闪记和最近记录 |
| alarms | 用户启用的定时同步/备份及已有回收站维护 |
| identity | 用户选择 Google Drive 后取得授权令牌 |
| contextMenus | 右键保存用户选中文字 |
| `<all_urls>` | 用户在网页剪藏、重访时恢复高亮、自动记录开启时的网页复制文字记录，以及连接用户指定的 WebDAV 地址；不自动上传网页浏览记录 |

单一用途：保存、管理和找回用户选择的网页摘录、笔记及可暂停的临时复制历史。

数据披露必须与实际行为一致：扩展处理用户保存的文本和关联 URL，WebDAV 凭据保存在本机，并仅用于连接指定服务器；用户选择同步后，记录和文件夹定义会传给其选定的服务。不要因“本地优先”而填写成“不访问任何网站内容”或“所有数据都不离开设备”。后台类别与措辞由发布者结合实际表单逐项核对。
